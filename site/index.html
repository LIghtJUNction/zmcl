Project Z / v0.1.0 · 开发预览

Minecraft 启动器

zmcl 是基于 Rust 与 Project Z 的原生启动器。提供 Java 版实例、加载器和内容管理，支持图形界面与命令行。

目前主要在 Linux 上开发和验证。功能覆盖与内存优化仍在进行中。

安装

Arch Linux

使用 AUR 包 zmcl-bin 安装官方预编译程序。

AUR
paru -S zmcl-bin

当前包为 0.1.0-1 开发预览。也可运行 yay -S zmcl-bin；更新和卸载由包管理器处理。

Linux x86_64

下载 v0.1.0 开发预览。此预编译包要求 glibc ≥ 2.43；安装和卸载方法随包提供。Java、Minecraft 与系统图形库单独安装。

文件校验值与安装记录 ↗

从源码构建

按仓库工具链安装 Rust。Linux 需要 X11/XWayland、OpenGL、FreeType 与 Fontconfig 开发库。

Shell
git clone --recurse-submodules \
  https://github.com/LIghtJUNction/zmcl.git
cd zmcl
cargo build --release --locked
./target/release/zmcl gui

Windows 和 macOS 的独立实机验收尚未完成。完整构建说明 ↗

开始使用

安装后，在应用菜单打开 zmcl，或运行 zmcl gui。创建实例时选择 Minecraft 版本和加载器，再安装游戏。

也可以通过命令行创建实例。下面使用明确的单机身份：

示例 · Minecraft 1.21.1
zmcl instance create survival --version 1.21.1
zmcl install survival
zmcl launch survival --offline Player

Microsoft 设备授权流程已接入，但真实账号的登录、刷新和启动仍待完整验收。

当前功能

以下是 v0.1.0 的主要能力。部分管理操作目前通过命令行提供，图形界面仍在补齐。

游戏与加载器
Java 版安装、修复和启动。原版 26.3、Fabric / Quilt / Forge 1.21.1 已有真实菜单记录；NeoForge 仍待实机验收。
实例
创建、配置、克隆、回收站和恢复；下载校验、缓存复用与损坏修复。
Modrinth
模组搜索与添加、mrpack 导入与导出。模组启停、更新、移除和恢复主要通过命令行完成。
世界与备份
命令行支持世界目录和 ZIP 的导入导出、克隆、快照、校验与恢复。现有验收包含合成存档，图形界面正在接入。
资源与服务端
资源包、光影包及本地 Java 服务端管理已有命令行入口。游戏内光影渲染与服务端世界运行仍需另行验收。
运行环境
下载并校验所需 Java。Horizon 官方启动器组件的下载、签名校验和版本运行已验证，完整游戏流程尚未验证。

资源占用

GUI 内存目标是低于 10 MiB，当前版本尚未达到。以下保留 v0.1.0 的公开测量结果，不将优化目标当作实测成绩。

Linux v0.1.0 · 源码 0337762 · 2026-11-20
测量项结果
主程序 ELF1.35 MiB 1,412,176 bytes
下载包 tar.gz633.64 KiB 648,849 bytes
GUI 空闲 PSS87.84 MiB 89,946 KiB
GUI 空闲 RSS106.18 MiB 108,728 KiB

内存来自 3 轮 × 11 个样本，取各轮中位数后再取中位数。条件为 Linux x86_64、Xvfb、llvmpipe 软件渲染、1024×720 空首页，暖机 20 秒。计入完整启动器进程树；不含显示服务、Java 和 Minecraft。

PSS 按份额计算共享内存，RSS 直接计算驻留页；两者不能混用。文件体积不含系统库、Java、游戏和缓存。该轮 zmcl 没有观察到换页。

开发计划

功能对照固定在 XMCL v0.73.1，完整覆盖尚未完成。当前优先处理以下工作：

  1. 降低 GUI 内存。Project Z 正在将界面后端统一到 zgpui；接入真实窗口并完成测量后再更新结果。当前发行版仍使用 zui-native。
  2. 补齐图形界面。把已有的世界、备份、资源和服务器管理接入窗口，减少日常操作对命令行的依赖。
  3. 完善账号和内容来源。完成真实账号流程验收，再补齐 CurseForge、FTB、Packwiz 等来源及复杂整合包场景。
  4. 扩展平台与协作能力。Windows/macOS 实测、签名自更新、无障碍、P2P 联机和云备份仍在待办中。Bedrock 尚未支持。
