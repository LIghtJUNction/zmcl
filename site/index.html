Project Z / v0.1.4 · 开发预览

Minecraft 启动器

zmcl 是基于 Rust 与 Project Z 的原生启动器。提供 Java 版实例、加载器和内容管理，支持图形界面与命令行。

提供 Linux 与 Windows 安装包。安装、窗口和游戏流程分别记录验收范围；功能覆盖与内存优化仍在进行中。

Linux tar.gz：解包和用户安装

先核对下方 SHA-256，再运行。前缀保持一致即可升级；安装器会给出本次程序的直接启动命令。

Shell
tar -xzf zmcl-0.1.4-linux-x86_64.tar.gz
cd zmcl-0.1.4-linux-x86_64
python3 scripts/install.py install --prefix "$HOME/.local"
"$HOME/.local/bin/zmcl" gui

自定义前缀可写为 "$HOME/Applications/zmcl portable"，启动时也使用相同目录下的 bin/zmcl。安装器不会修改 PATH。

DEB：使用 apt 安装

核对 SHA-256 后，让 apt 检查运行库和必需依赖。用户实例、存档及账号数据不属于软件包的文件清单。

Shell
sudo apt install --no-install-recommends ./zmcl-0.1.4-linux-x86_64.deb
/usr/bin/zmcl --version
/usr/bin/zmcl gui

CA 证书是显式依赖，在不安装推荐包的最小 Debian 环境中也会安装。升级继续安装新版 DEB，卸载使用 sudo apt remove zmcl。

Windows ZIP：解包和用户安装

在 PowerShell 中进入 ZIP 所在目录，核对 SHA-256 后运行。若没有 py -3，使用已安装的 Python 3.8 或更新版本。

PowerShell
Expand-Archive .\zmcl-0.1.4-windows-amd64.zip -DestinationPath .
Set-Location .\zmcl-0.1.4-windows-amd64
py -3 scripts/install.py install --prefix "$env:LOCALAPPDATA\Programs\zmcl"
& "$env:LOCALAPPDATA\Programs\zmcl\bin\zmcl.exe" gui
SHA-256 与构建身份

下载文件的摘要应与对应行完全一致。Linux 用 sha256sum 文件名，PowerShell 用 Get-FileHash 文件名 -Algorithm SHA256 检查。

Arch Linux / AUR

zmcl-bin 已公开 0.1.4-1 配方（源码 a769068）。可用 paru -S zmcl-bin 或 yay -S zmcl-bin 安装，并用 zmcl --version 核对实际程序。公开新克隆构建、本机升级与已安装界面验收已通过，真实官方更新查询返回当前 0.1.4。

从源码构建

按仓库工具链安装 Rust。Linux 默认 CPU 后端需要 X11/XWayland、FreeType 与 Fontconfig 开发库。

Shell
git clone --recurse-submodules \
  https://github.com/LIghtJUNction/zmcl.git
cd zmcl
cargo build --release --locked
./target/release/zmcl gui

完整构建说明 ↗。macOS 应用构建和桌面流程仍待验收。

开始使用

安装后，使用安装器显示的完整路径打开程序。Linux 桌面入口也可从应用菜单启动；PATH 已指向本次安装时可运行 zmcl gui。创建实例时筛选 Minecraft 发行版、选择加载器，默认创建并安装；也可先选择仅创建。

也可以通过命令行创建实例。下面使用明确的单机身份：

示例 · Minecraft 1.21.1
zmcl instance create survival --version 1.21.1
zmcl install survival
zmcl launch survival --offline Player

Microsoft 设备授权流程已接入，但真实账号的登录、刷新和启动仍待完整验收。

当前功能

v0.1.4 改进安装完成提示、来源识别和手动更新检查，并通过 Linux 安装更新与 Windows 原生发行验收。既有创建、管理和游戏记录保留各自版本；本轮的窗口与文件夹具不等同于真实账号或游戏流程。

安装与更新
Settings 展示当前版本、程序位置和安装来源。手动检查官方更新，区分新版本、已最新和本机版本更高；失败可重试。下载后按原安装渠道更新，检查本身不改写程序。
游戏与加载器
Java 版安装、修复和启动。原版 26.3、Fabric / Quilt / Forge 1.21.1 已有此前构建的真实菜单记录；本版未重跑实际游戏，NeoForge 仍待实机验收。
实例
筛选官方发行版、建议不重复的名称，选择创建并安装或仅创建。保留配置、克隆、回收站和恢复，以及下载校验、缓存复用与损坏修复。
Modrinth
模组搜索与添加、mrpack 导入与导出。模组启停、更新、移除和恢复主要通过命令行完成。
世界与备份
已有历史 GUI 验收覆盖世界目录导入、ZIP 导出、备份与确认恢复，并保留恢复前快照。CLI 还提供克隆等操作；相关合成存档验收不等同于实际游戏内游玩。
资源与服务端
资源包、光影包及本地服务器已有 GUI 管理入口。0.1.3 的历史验收覆盖未托管资源文件保留、创建服务器及 EULA 未接受时拒绝启动；真实联网下载、光影渲染和开服仍待分别验收。
运行环境
下载并校验所需 Java。Horizon 官方启动器组件的下载、签名校验和版本运行已验证，完整游戏流程尚未验证。

开发计划

功能对照固定在 XMCL v0.73.1，完整覆盖尚未完成。当前优先处理以下工作：

  1. 降低 GUI 内存。已接入 zgpui 0.1.5 的真实原生 CPU 后端；继续降低启动、重绘和按需 CLI / Python 的操作期开销，保持主进程与完整相关树的测量。
  2. 补齐图形界面。完善已有管理页面，接入更多仍只通过 CLI 提供的操作，并补足大存档、复杂整合包和真实服务端的窗口验收。
  3. 完善账号和内容来源。完成真实账号流程验收，再补齐 CurseForge、FTB、Packwiz 等来源及复杂整合包场景。
  4. 扩展平台与协作能力。继续扩展 Windows 系统版本与真实游戏验收，补足 macOS 应用构建和桌面流程；签名自更新、无障碍、P2P 联机和云备份仍在待办中。Bedrock 尚未支持。
